# 사라지는 동네, 남는 동네 — 데이터 대시보드

부산광역시교육청 정보영재교육원 · 학생 성과 발표회 2기
**팀 이단우와아이들** (이단우 · 송예겸 · 황석주 · 임지온, 지도교사 유근찬 선생님)

연구보고서 「사라지는 동네, 남는 동네 — 일자리와 청년 유출로 본 지방소멸위험」의
수치를 한 화면에서 볼 수 있는 대시보드입니다.
Flask 자기소개 스타터에서 출발했고, 원래의 자기소개 페이지는 `/me` 주소에 그대로 남아 있습니다.

## 폴더 구조

```
starter_flask/
├── app.py             ← Flask 서버 ( /  대시보드,  /me  자기소개 )
├── index.html         ← 대시보드 본체 (정적 파일 — GitHub Pages에서 바로 열림)
├── requirements.txt
├── templates/
│   └── index.html     ← 원래의 자기소개 페이지 (건드리지 않음)
└── static/
    ├── dashboard.css  ← 대시보드 디자인
    ├── style.css      ← 자기소개 페이지 디자인 (따로 분리)
    ├── data.js        ← 보고서에서 옮긴 수치 데이터 (출처 포함)
    ├── charts.js      ← 차트 4종 (React 디자인을 vanilla JS + SVG로 변환)
    ├── calc.js        ← 소멸위험지수 계산기 (조절 막대 → 지수·등급 계산)
    ├── hero.js        ← 스크롤하면 섹션이 나타나는 효과
    └── fonts/
```

## 내 컴퓨터에서 실행하기

```
pip install -r requirements.txt   (처음 한 번만)
python app.py
```

브라우저에서 http://127.0.0.1:5000 접속. 종료는 터미널에서 `Ctrl + C`.
대시보드는 순수 정적 파일이라 `index.html`을 그냥 더블클릭해도 열립니다.

## GitHub에 올리고 QR 만들기

1. **GitHub에 새 저장소 만들기** — 보고서에 적은 이름 그대로: `team-LeeDanWoo-and-Idle`
2. **이 폴더를 업로드** (웹에서 "uploading an existing file"로 전부 끌어다 놓거나, git 사용 시):
   ```
   git init
   git add .
   git commit -m "지방소멸위험 연구 대시보드"
   git branch -M main
   git remote add origin https://github.com/<내아이디>/team-LeeDanWoo-and-Idle.git
   git push -u origin main
   ```
3. **GitHub Pages 켜기** — 저장소의 Settings → Pages → Branch를 `main` / `(root)`로 선택 후 Save.
   1~2분 뒤 `https://<내아이디>.github.io/team-LeeDanWoo-and-Idle/` 에서 대시보드가 열립니다.
4. **QR 만들기** — 아래 주소의 `<배포주소>` 자리에 위 Pages 주소를 넣고 브라우저로 열면
   QR 이미지가 나옵니다. 저장해서 보고서 [팀이 채울 부분]에 붙여 넣으세요.
   ```
   https://api.qrserver.com/v1/create-qr-code/?size=300x300&data=<배포주소>
   ```

## 대시보드 구성 (보고서 Ⅲ-2 요구사항 반영)

| 화면 | 검증하는 내용 |
|---|---|
| 시작화면 | 제목 · 팀 · 규모 (부산 9개 구 / 전국 55개 시군구) — 움직이는 요소 없음 |
| 01 연구 질문과 가설 | 주가설을 '원인 → 경로 → 결과' 세 칸으로 나누고 각 고리의 r을 표시 |
| 02 직접 계산해보기 | 조절 막대 2개로 소멸위험지수를 직접 계산 — 등급과 비슷한 구를 바로 확인 |
| 03 한눈에 보기 | 소멸위험지역 62곳, 부산 청년 순유출 8,550명 등 핵심 수치 4개 |
| 04 꺾은선 (지수 + ★등급선) | 부산 9개 구의 위험 순위 — 영도구 23.3이 '경계' 하단 |
| 04 산점도 (r=+0.67) | 주가설의 둘째 고리 "청년 유출 → 소멸위험" |
| 04 막대 (고령인구 비중) | 원도심 4개 구(영도·서·중·동)가 30% 이상 |
| 04 도넛 (3유형 55곳) | 부산 원도심이 속한 '원도심 쇠퇴형'의 위치 |
| 04 표로 보기 | 차트와 같은 데이터를 표로 (스크린리더·인쇄용) |
| 05 두 개의 고리 | 상관계수 4개를 |r| 막대와 함께 비교 |
| 06 발견한 것과 제안 | 결론 5가지 + 정책 제안 2가지 |
| 07 만든 사람들 | 팀원과 소속 |

### 02 계산기가 쓰는 공식

소멸위험지수 = **20~39세 여성 비중 ÷ 65세 이상 비중 × 100**

`data.js`에 적힌 보고서 원표의 지수와 이 계산이 실제로 맞는지 확인했습니다.

| 맞춰볼 값 | 계산 결과 | 보고서 표의 값 |
|---|---|---|
| 영도구 (8.0 / 34.2) | 23.4 | 23.3 |
| 남구 (11.0 / 24.9) | 44.2 | 44.2 |
| 농어촌 낙후지역 평균 (4.8 / 43.4) | 11.1 | 11.1 |

등급 경계(20, 40)는 따로 적어 두지 않고 `data.js`의 `levels`를 그대로 읽어 씁니다.
그래서 나중에 `data.js`의 기준만 고치면 계산기도 같이 바뀝니다.

## 디자인 출처

21st.dev에서 받은 React 컴포넌트를 프레임워크 없이 도는 JavaScript + SVG로 변환해 사용했습니다.

| 원본 React 컴포넌트 | 변환된 파일 | 바꾼 방법 |
|---|---|---|
| Slider (Radix UI) | `static/calc.js` + `dashboard.css` | 네이티브 `<input type="range">` 위에 CSS로 같은 모양을 다시 그림 — 트랙 두 겹 대신 `linear-gradient` 한 겹, 손잡이 위치는 브라우저에 맡김 |
| PointsChart (recharts) | `renderLineChart` | 별(★) 기준선·점선 그리드·모노톤 곡선을 직접 계산 |
| Chart/Tooltip (shadcn) | `renderScatterChart`, 공용 툴팁·범례 | 팝오버 툴팁과 사각 스와치 범례를 그대로 재현 |
| ChartContainer (shadcn) | `renderDonutChart` | 조각 사이 2px 간격을 배경색 stroke로 처리 |

색은 색약 구분(CVD)·명도 대역·대비 검사를 모두 통과한 3색만 씁니다 —
blue `#3987e5`, orange `#d95926`, aqua `#199e70` (배경 `#141414` 기준).
화면 장식은 전부 무채색이고, **색은 데이터에만** 씁니다.
그래서 계산기의 조절 막대도 흰색·회색이고, 색은 등급 배지와 눈금자에만 나타납니다.

시작화면에는 애니메이션이 하나도 없고 글자가 전부 HTML에 그대로 들어 있습니다.
본문의 스크롤 등장 효과는 `<head>`에서 붙이는 `js-on` 클래스가 있을 때만 켜지므로,
**JavaScript가 실행되지 않아도 화면이 비지 않습니다.** (발표 현장에서 가장 중요한 안전장치)

## 자주 나는 오류

| 증상 | 해결 |
|---|---|
| `'python'은(는) 내부 또는 외부 명령...` | Python 설치 시 "Add to PATH" 체크 안 함 → 재설치 또는 py 명령 사용 |
| `ModuleNotFoundError: No module named 'flask'` | `pip install flask` 실행 |
| `Address already in use` / 포트 오류 | 이미 켜져 있는 서버(다른 터미널)를 Ctrl+C로 끄기 |
| 페이지가 안 바뀜 | 브라우저 새로고침(Ctrl+F5). 그래도 안 되면 서버 껐다 켜기 |
| 조절 막대를 움직여도 숫자가 그대로 | `static/calc.js` 파일이 빠졌는지 확인. 이 경우에도 영도구 기준값(23.4 · 경계)은 그대로 보입니다 |
