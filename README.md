## 폴더 구조

화면은 **표지**와 **본문** 두 장으로 나뉩니다.
표지에서 `데이터로 확인하기`를 누르면 본문으로 넘어가고, 본문 왼쪽 위 `← 표지로`로 돌아옵니다.

```
team-LeeDanWoo-and-Idle/
├── index.html         ← 표지 (제목 + 배경 물결 + 버튼). 여기가 첫 화면
├── dashboard.html     ← 본문 (01~08 섹션 + 출처). 버튼을 누르면 오는 곳
├── qr.png / qr.svg    ← 표지 주소로 가는 QR 코드 (보고서 붙여넣기용)
├── .nojekyll          ← GitHub Pages가 파일을 건드리지 않게 하는 표시
└── static/
    ├── dashboard.css  ← 디자인 (두 장이 같은 파일을 쓴다)
    ├── data.js        ← 보고서에서 옮긴 수치 데이터 (출처 포함)
    ├── charts.js      ← 차트 4종 (React 디자인을 vanilla JS + SVG로 변환)
    ├── calc.js        ← 소멸위험지수 계산기 (조절 막대 → 지수·등급 계산)
    ├── wave.js        ← 표지 배경 물결 (canvas). 표지에서만 쓴다
    ├── hero.js        ← 스크롤하면 섹션이 나타나는 효과. 본문에서만 쓴다
    └── fonts/
```

## 실행 방법 — 설치할 것이 없습니다

**순수 정적 사이트라 서버가 필요 없습니다.** 파이썬도, Node.js도, 빌드도 없습니다.

| 언제 | 어떻게 |
|---|---|
| 발표장에서 관객에게 | QR 찍기 → https://rbnsng7.github.io/team-LeeDanWoo-and-Idle/ |
| 인터넷이 안 될 때 | `index.html` **더블클릭** → 버튼을 누르면 본문으로 이동. 차트·계산기 전부 작동 |
| 본문만 바로 보고 싶을 때 | `dashboard.html` 더블클릭 |
| 내용을 고친 뒤 확인 | 더블클릭 후 `Ctrl + F5` (그냥 새로고침이 아니라 강력 새로고침) |

이게 가능한 이유는 **외부에서 받아오는 것이 하나도 없기** 때문입니다.
CDN 스크립트도, 서버에서 데이터를 불러오는 코드도 없고, 모든 경로가 상대경로(`static/...`)입니다.
그래서 USB에 폴더째 복사해 가도 그대로 열립니다 — 학교 와이파이가 막힐 때를 대비한 보험입니다.

> 예전에는 `app.py`(Flask)로 서버를 띄웠지만, 어차피 정적 파일을 그대로 내보내기만 해서
> 하는 일이 없었습니다. GitHub Pages로 배포하면서 삭제했습니다.
> (기록이 필요하면 `git log`에 그대로 남아 있습니다)

## QR 코드

폴더 안에 이미 만들어져 있습니다. 담긴 주소는
`https://rbnsng7.github.io/team-LeeDanWoo-and-Idle/` 입니다.

| 파일 | 언제 쓰나 |
|---|---|
| `qr.png` | 한글(HWP)·워드에 붙여넣기. 900×900px |
| `qr.svg` | 크게 인쇄할 때. 아무리 키워도 안 깨짐 (포스터·현수막용) |

만들 때 확인한 것:

- 오류정정 **Q(25%)** 수준으로 만들어, 종이가 구겨지거나 프린터 상태가 나빠도 읽힙니다
- 실제로 디코딩해서 주소가 정확히 나오는지 확인했습니다
- **150×150px까지 줄여도** 읽힙니다. 보고서에서는 **2cm × 2cm 이상**으로 넣으세요
- QR 둘레의 흰 여백은 지우면 안 됩니다. 스캐너가 그 여백으로 QR을 찾습니다

주소가 바뀌면 다시 만들어야 합니다.

```bash
python -m pip install segno
```

```bash
python -c "import segno; segno.make('https://rbnsng7.github.io/team-LeeDanWoo-and-Idle/', error='q').save('qr.png', scale=20, border=4)"
```

| 06 발견한 것 | 분석에서 확인한 결론 5가지 |
| 07 정책 제안 | 보고서 Ⅳ-1의 정책 제안 ①② — 각 제안 아래에 근거 수치를 함께 표시 |
| 08 만든 사람들 | 팀원과 소속 |

### 02 계산기가 쓰는 공식

소멸위험지수 = **20~39세 여성 비중 ÷ 65세 이상 비중 × 100**

`data.js`에 적힌 보고서 원표의 지수와 이 계산이 실제로 맞는지 확인했습니다.

| 맞춰볼 값 | 계산 결과 | 보고서 표의 값 |
|---|---|---|
| 영도구 (8.0 / 34.2) | 23.4 | 23.3 |
| 남구 (11.0 / 24.9) | 44.2 | 44.2 |
| 농어촌 낙후지역 평균 (4.8 / 43.4) | 11.1 | 11.1 |

등급 경계(20, 40)는 따로 적어 두지 않고 `data.js`의 `levels`를 그대로 읽어 씁니다.
그래서 나중에 `data.js`의 기준만 고치면 계산기도 같이 바뀝니다.

## 디자인 출처

21st.dev에서 받은 React 컴포넌트를 프레임워크 없이 도는 JavaScript + SVG로 변환해 사용했습니다.

| 원본 React 컴포넌트 | 변환된 파일 | 바꾼 방법 |
|---|---|---|
| Slider (Radix UI) | `static/calc.js` + `dashboard.css` | 네이티브 `<input type="range">` 위에 CSS로 같은 모양을 다시 그림 — 트랙 두 겹 대신 `linear-gradient` 한 겹, 손잡이 위치는 브라우저에 맡김 |
| HeroWave (canvas) | `static/wave.js` | `useRef`/`useEffect` 대신 DOM에서 canvas를 직접 찾음. 계산 결과를 작은 캔버스에 그린 뒤 확대 |
| PointsChart (recharts) | `renderLineChart` | 별(★) 기준선·점선 그리드·모노톤 곡선을 직접 계산 |
| Chart/Tooltip (shadcn) | `renderScatterChart`, 공용 툴팁·범례 | 팝오버 툴팁과 사각 스와치 범례를 그대로 재현 |
| ChartContainer (shadcn) | `renderDonutChart` | 조각 사이 2px 간격을 배경색 stroke로 처리 |

색은 색약 구분(CVD)·명도 대역·대비 검사를 모두 통과한 3색만 씁니다 —
blue `#3987e5`, orange `#d95926`, aqua `#199e70` (배경 `#141414` 기준).
본문에서는 화면 장식을 전부 무채색으로 두고 **색은 데이터에만** 씁니다.
그래서 계산기의 조절 막대도 흰색·회색이고, 색은 등급 배지와 눈금자에만 나타납니다.
표지의 물결은 데이터가 없는 화면이라 이 규칙에서 제외했습니다.

**JavaScript가 실행되지 않아도 화면이 비지 않습니다.** (발표 현장에서 가장 중요한 안전장치)

- 표지의 글자와 버튼은 HTML에 그대로 있고, 물결은 그 위에 덧그리는 장식일 뿐입니다
- 본문의 스크롤 등장 효과는 `<head>`에서 붙이는 `js-on` 클래스가 있을 때만 켜집니다

배경 물결은 픽셀을 하나씩 계산하는 방식이라 무겁습니다. `static/wave.js`에 세 가지 안전장치를 뒀습니다.

- 화면 해상도의 1/4만 계산해서 늘려 그린다
- 초당 60번이 아니라 30번만 그린다
- 첫 프레임이 12ms를 넘으면 해상도를 한 번 더 낮춘다 (느린 노트북 대비)

운영체제에서 '동작 줄이기'를 켜 두었으면 물결이 정지 화면 한 장으로 바뀝니다.
물결이 너무 진하거나 옅으면 `wave.js` 맨 위의 `GAIN` 값을 바꾸면 됩니다.

## 자주 나는 오류

| 증상 | 해결 |
|---|---|
| 고친 내용이 화면에 안 나옴 | 브라우저에서 `Ctrl + F5` (그냥 새로고침 말고 강력 새로고침) |
| 글씨만 나오고 디자인이 없음 | `static` 폴더를 `index.html`과 **같은 위치**에 뒀는지 확인. 폴더째 옮겨야 합니다 |
| 차트가 안 보임 | `static/charts.js`나 `static/data.js`가 빠진 경우. `F12` → Console 탭에 빨간 글씨가 있는지 확인 |
| 조절 막대를 움직여도 숫자가 그대로 | `static/calc.js`가 빠진 경우. 이때도 영도구 기준값(23.4 · 경계)은 그대로 보입니다 |
| 팀 이름 글꼴이 다르게 나옴 | `static/fonts/` 폴더가 빠진 경우 (5.4MB라 복사가 느릴 수 있음) |
| 표지 배경이 까맣기만 함 | `static/wave.js`가 빠졌거나, '동작 줄이기' 설정이 켜져 있음. 글자와 버튼은 정상 작동 |
| 표지 버튼을 눌러도 안 넘어감 | `dashboard.html`이 `index.html`과 같은 위치에 있는지 확인 |
| 표지 배경이 버벅임 | `wave.js` 맨 위 `let scale = 4`를 `8`로 키우면 가벼워집니다 |

### GitHub에 올릴 때

| 증상 | 해결 |
|---|---|
| `git push` 했더니 창이 떠서 로그인하라고 함 | 정상입니다. 처음 한 번만 GitHub 로그인하면 다음부터는 안 물어봅니다 |
| `Repository not found` | github.com에 저장소를 아직 안 만들었거나 이름이 다름. 이름은 정확히 `team-LeeDanWoo-and-Idle` |
| `failed to push some refs` / `rejected` | 저장소 만들 때 "Add a README file"을 체크했을 때 남. `git pull --rebase origin main` 실행 후 다시 `git push` |
| Pages 주소가 404 | ① Settings → Pages 설정을 저장했는지 ② 저장 후 1~2분 기다렸는지 ③ 주소 끝에 `/`를 빼먹지 않았는지 |
| 페이지는 열리는데 글씨만 나오고 디자인이 없음 | `static/` 폴더가 통째로 안 올라간 경우. `git status`로 빠진 파일 확인 |
